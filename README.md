# HealthFirst Pharmacy Inventory System

## Project Description 

The HealthFirst Pharmacy Inventory Management System (PIMS) is a 
Java desktop application designed to assist a pharmacy with inventory
management, sales proceeding and business reporting

The system is being developed as part of the Programming 732 assignment.

## Main Features

 - User authentication 
 - Role-based access
 - Medicine inventory management
 - Supplier management 
 - Cashier Point of Sale (POS)
 - Sales processing 
 - Bill generation
 - Sales reports
 - Item-wise reports 
 - Low-stock reports
 - Expiry reports

## Technologies

 - Java
 - Swing/AWT
 - JDBC
 - MySQL
 - IntelliJ IDEA
 - Git
 - GitHub

## User Roles 

Administrators will be able to 

 - Manage medicines
 - Manage suppliers
 - Manage cashier accounts
 - View reports

## Cashier

Cashiers will be able to 

 - Check medicine availability 
 - Process sales
 - Generate customer bills
